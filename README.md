# ❌ Tic-Tac-Toe Game ⭕

A classic, interactive, and beautifully designed Tic-Tac-Toe game built with web technologies. Play right in your browser with smooth user experience!

[![Live Demo](https://img.shields.io/badge/Live-Demo-brightgreen?style=for-the-badge&logo=github)](https://rtechcoding.github.io/tik-tak-toe-game/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg?style=for-the-badge)](https://opensource.org/licenses/MIT)

---

## 🚀 Features

* **Interactive Gameplay**: Classic 3x3 grid mechanics for two players.
* **Responsive Design**: Looks and plays great on both desktop and mobile devices.
* **Clean UI/UX**: Minimalist interface with smooth animations and instant win-detection.

---

## 🕹️ How to Play

1. Visit the live game link: [Play Tic-Tac-Toe](https://rtechcoding.github.io/tik-tak-toe-game/)
2. Player **X** always goes first.
3. Click on any empty square to place your mark.
4. The first player to align 3 of their marks horizontally, vertically, or diagonally wins the game!
